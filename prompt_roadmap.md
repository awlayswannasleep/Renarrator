# Prompt Roadmap: Rust + Tauri KeyTrigger Sound Engine (Windows)

Настоящее руководство (Roadmap & Prompt Kit) предназначено для поэтапной разработки фонового приложения на **Rust (Tauri v2)** под **Windows**. 

Программа отслеживает глобальный ввод с физической клавиатуры, сопоставляет последовательность нажатий клавиш с пользовательскими триггер-словами (независимо от раскладки ОС) и воспроизводит аудиоэффекты с поддержкой полифонии, рандомизации вероятностей и гибкой регулировки громкости.

---

## 1. Спецификация и Архитектура Проекта

### 1.1. Технологический Стек
* **Язык бэкенда:** Rust (edition 2021)
* **GUI / Shell Framework:** Tauri v2 (режим фонового приложения с поддержкой System Tray)
* **Глобальный перехват клавиатуры:** `rdev` или `windows-sys` (Low-Level Keyboard Hook: `SetWindowsHookExW`)
* **Аудио-движок:** `rodio` (работа через cpal / DirectSound / WASAPI)
* **Форматы аудио:** `.mp3`, `.wav`, `.ogg`
* **Сериализация / Конфиг:** `serde`, `serde_json` (хранение в `%APPDATA%/<app_id>/config.json`)

---

### 1.2. Диаграмма Потоков Данных (Architecture Flow)

```
[ Физическая Клавиатура ]
          │
          ▼
[ Global Keyboard Hook (WinAPI / rdev) ] ── (Фильтрация VK Code / Physical Scancode)
          │
          ▼
[ Key Buffer Manager ]
  ├── Регистр: Игнорируется (Case-insensitive)
  ├── Символы-сбросы: Space, Enter, Backspace, Punctuation
  └── Таймаут: > 2.0с между нажатиями ──► (Очистка буфера)
          │
          ▼
[ Trie / Pattern Matcher ] ──► Поиск совпадений по Key Sequences
          │
          ▼ (Match Found!)
[ Audio Dispatcher Engine ]
  ├── Проверка типа наложения (Overlap vs Interrupt)
  ├── Расчет вероятностей (Normalized Probabilities)
  ├── Применение Громкости (Master Volume * Sound Volume)
  └── [ Rodio Audio Sink ] ──► Динамики
```

### Phase 3: Менеджер Буфера Ввода и Детектор Слов

#### Промпт для Claude:
```text
Ты — Архитектор Rust приложений. Разрабатываем модуль обработки и сопоставления набранного текста (`src/buffer_manager.rs`).

Логика работы буфера:
1. Регистронезависимость: Все символы приводятся к единому регистру.
2. Таймаут ввода: Если между нажатиями прошло более 2.0 секунд (`std::time::Duration`), буфер полностью очищается.
3. Символы сброса: При нажатии Space, Enter, Backspace, Tab, Escape или знаков препинания буфер мгновенно очищается.
4. Детект совпадений:
   - У нас есть словарь зарегистрированных слов/фрагментов.
   - Сравнение происходит сразу при каждом нажатии клавиши.
   - При совпадении с ключевым словом генерируется событие `TriggerMatched(trigger_id)`.
   - Если слово сработало (например, "банан"), текущий буфер сбрасывается, чтобы исключить дублирование срабатываний.

Создай высокопроизводительный `BufferManager` с модульными тестами (unit tests) для проверки таймаутов, символов сброса и детекта слов.
```

### Phase 4: Аудио-Движок (Rodio, Нормализация Вероятностей, Полифония)

#### Промпт для Claude:
```text
Ты — Rust Audio Systems Engineer. Разрабатываем аудио-модуль `src/audio_engine.rs` на базе библиотеки `rodio`.

Требования:
1. Поддержка форматов `.mp3`, `.wav`, `.ogg`.
2. Полифония и Наложение (Overlap):
   - Флаг `allow_overlap` (bool): если `true`, новые звуки накладываются на текущие. Если `false`, текущее воспроизведение останавливается перед проигрыванием нового звука.
3. Управление Громкостью:
   - `master_volume` (0.0 .. 1.0) — общая громкость приложения.
   - `sound_volume` (0.0 .. 1.0) — громкость конкретного аудиофайла.
   - Итоговая громкость воспроизведения = `master_volume * sound_volume`.
4. Расчет вероятностей (Normalized Probability Weights):
   - Каждому звуку задан вес (weight, например 60 и 30).
   - Сумма весов пересчитывается в 100% (нормализация): P(i) = weight_i / sum(weights).
   - Функция случайного выбора `rand::thread_rng()` выбирает ровно один звук согласно нормализованным шансам.

Напиши поток безопасный `AudioEngine` (`Arc<Mutex<AudioEngine>>` или `tokio::sync::mpsc` command loop) с полной реализацией воспроизведения.
```

## 4. Чек-лист Проверки Готовности Проекта

- [ ] Приложение корректно сворачивается в трей и не завершает работу при закрытии окна.
- [ ] Физические клавиши считываются одинаково на русской и английской раскладках.
- [ ] Пауза между буквами > 2 секунд сбрасывает ввод.
- [ ] Нажатие Space / Enter / Backspace мгновенно очищает буфер.
- [ ] Слово "банан" вызывает воспроизведение звука ровно 1 раз без дублирования.
- [ ] Нормализация весов правильно выбирает случайный звук из списка.
- [ ] Настройки сохраняются в `%APPDATA%/KeySoundTrigger/config.json`.
